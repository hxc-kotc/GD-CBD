# Real GD-CBD synthesis scheme (source for Figure 1a)

Source: image the user shared 2026-10-15, a chemist's synthesis-scheme figure with three panels — (a) the GD2 dendrimer structure, (b) synthesis of a GD2-norketamine conjugate, (c) synthesis of the GD2-CBD conjugate. Only panel (c) is ours; the user said "don't worry about ketamine though," so panel (b) was never used.

- `GD2-CBD_synthesis_scheme.png` — the full three-panel source image, unmodified, for provenance.
- `panel_c_GD2-CBD.png` — panel (c) cropped out via whitespace-gap detection.
- `panel_c_GD2-CBD_clean.png` — same crop with the source figure's own "(c)" panel label painted out (our own panel-letter "a" replaces it) and re-tightened to content. **This is the file `figures/mockups/build_fig1_mock.py` actually uses** for Figure 1 panel a.

Real route shown: CBD + azido-PEG4-COOH → bifunctional PEG linker-CBD (in DMF); GD2 (OH96) + propargyl bromide → GD2-acetylene (4); CuAAC click of the two → GD-CBD (7). This is real chemistry, not a mockup — Figure 1a's status tag is "Have," the only non-illustrative panel in that figure.
