# GD-CBD — PI working session, 2 Nov 2026: summary

Spencer, Sujatha, Durgadas, and Preeti went through the GD-CBD data and figure plan file by file. Below is what was decided, what's still open, and who owns what.

## Bottom line

- **Framing narrowed:** this is a CBD paper, not a pain paper. Claim set: GD-CBD is a better CB<sub>2</sub> agonist than free CBD, better formulated and more soluble, demonstrated in two models (incision pain, seizures) as examples — not a development program for acute pain or acute seizures specifically.
- **Paw incision/paw edema model: cut.** Not enough animals for a clean version without a full new cohort; the existing story (incision + seizures) is enough.
- **No toxicity/safety figure.** CBD's own toxicity is chronic-exposure only — not something an acute-dosing design can show. The liver work that remains is about **stability**, not toxicity.
- **Biodistribution: small and settled.** Existing GD-Cy5 images from the flank-incision model (not a new CBD-conjugated-Cy5 study). No new large dosing study. IVIS dropped from the paper entirely.
- **New structural requirement: CB<sub>2</sub> overexpression after insult**, shown in each of the three systems the paper uses (in vitro microglia, DRG after incision, neurons after seizure) — this is what justifies using a CB<sub>2</sub> agonist at all. Cheap stains/blots on material already in hand, not a gate on the paper.
- **New analysis:** per-animal slope from baseline to ~72h, added alongside the existing AUC for the flank-incision data (not a replacement).
- **Figure quality standard set:** Lin Peng's papers are the visual model for how figures should look. Current placeholder graphs were explicitly rejected as a style — "not Excel graphs."
- **Target:** decent outline and paper ready by December (a hope, not a locked date).

## Decisions

| Item | Decision |
|---|---|
| Paw incision / paw edema | Cut entirely, including as supporting data |
| Toxicity / safety figure | Not pursued — design can't show it |
| Figure quality | Match Lin Peng's papers; Preeti to share |
| IVIS | Out of the paper |
| Biodistribution compound | GD-Cy5 (existing material), not a new CBD-conjugated compound |
| SE biodistribution | Not shown — already published elsewhere |
| In vitro cell type | Microglia only (not macrophages) |
| CB<sub>2</sub> overexpression | Required in each model system, before the efficacy readout |
| Slope-to-72h analysis | Added as a secondary readout; AUC stays primary |
| Liver metabolism | Keep — free CBD vs. GD-CBD |
| Flank-incision cohort | ~2 more animals per group; unequal group sizes (more GD-CBD) accepted |
| Delayed-therapy seizure groups | Not in this paper — saved for future chronic/TLE work |
| Synthesis figure | Owned by Durgadas |

## CB2 binding — what's in hand

- GD-CBD is about **6-fold more potent than free CBD** on a drug basis (CB<sub>2</sub>, drug-basis comparison; conjugate-basis would look even better).
- THC used as the nanomolar positive control.
- Durgadas repeating the binding curve with more concentration points next week.
- In vitro potency is millimolar — accepted as consistent with the rest of this drug class, not a concern.
